## 1. 业务需求（译文 §3.3 完整摘编）

> 以下内容摘自[中文译文](../Ocean-Island-酒类供应商系统增强需求-中文版.md) §3.3「产品类目管理」。本节在正式修订版中为**新增章节**（2026-07-16 草稿无此需求）。

### 3.3 产品类目管理

产品类目必须通过 **Vendor Settings** 下的**共享类目库**管理。

获授权用户必须能够：

- 创建与编辑类目；
- 启用与停用类目；
- 存储英文与简体中文类目名称；
- 在创建或编辑产品时选择已有类目；
- 查看某类目当前是否已被产品使用。

**已被一个或多个产品使用的类目不得被永久删除。**

Vendor 可停用类目以阻止其被分配给新产品。**已分配该类目的既有产品必须保持不变。**

## 3. 验收标准

| # | 验收项 | 判定方式 |
|---|--------|----------|
| AC-1 | 获授权用户可在 Vendor Settings 创建类目并填写英文与中文名 | 创建后列表可见两语名；切换界面语言后类目名随之切换（英文界面显英文名、中文界面显中文名；缺中文名回退英文） |
| AC-2 | 类目可启用/停用 | 停用后：**产品建/改表单的类目下拉不再出现该类目**；**已分配该类目的既有产品保持不变**（产品详情仍显示该类目，不报错、不清空） |
| AC-3 | 建/改产品时可选择已有类目 | 产品表单类目选择器数据源为该 vendor 的启用中类目；保存后产品详情与列表显示所选类目 |
| AC-4 | 可查看类目是否被产品使用 | 类目列表展示"已用于 N 个产品"（或"未使用"）；点击可跳转到该类目下的产品列表 |
| AC-5 | 被产品使用的类目不得永久删除 | 对已被使用的类目执行删除 → 返回 409 并提示"仍有 N 个产品使用此类目"，提供"改为停用"引导；确认库内该类目行未被删除 |
| AC-6 | 未被任何产品使用的类目可删除 | 删除成功，列表不再出现 |
| AC-7 | 类目名在 vendor 内唯一 | 同 vendor 创建同名（英文名）类目 → 409 |
| AC-8 | 产品导入校验类目取值（§7.2） | 导入文件含未知类目名的行 → 该行进入错误报告并说明"类目不存在"，其余合法行正常导入 |
| AC-9 | 餐厅端可按类目筛选目录（FR-B6） | 餐厅账号在目录页按类目筛选，结果正确；类目名按其界面语言显示 |
| AC-10 | 不影响其他 vendor | 未启用类目库的 vendor 的产品管理与餐厅采购流程行为与改造前一致（零回归） |

| 维度 | 代码库现状（v20260705） | 差距 |
