## 专项：手机号拆分为「国家字段 + 号码字段」

结论：全库 **37 个电话列 / 29 张表、7,694 个号码**，只有报价的 2 张表有国家列（`phone_country_code`），而且只填了一部分、写法不一；其余全部把国家区号和号码混存在一个字符串里。没有一列达到「已优化」标准。
