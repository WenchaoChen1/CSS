## 0. 先读：四条总原则

1. **尺寸单位**：代码里写 `rem(N)`（= N/16 rem），根字号 `font-size: min(0.833vw, 16px)`（`src/app/styles/global.scss`），即 1920 宽时 1rem = 16px。**原型一律按 N px 画（设计稿尺寸），不要乘 0.75。** 1440 画板上侧栏 248px、内容区约 1150px。
2. **可访问性修正**：系统原色里有几组达不到 4.5:1（橙底白字 3.00、橙色文字 3.00、次要灰字 3.09、绿字 2.72、错误红字 3.18）。原型里凡是"文字"或"承载文字的底色"，一律用 A1 表的"原型取值"列；系统原值只保留给装饰（指示条、logo、分隔线、图标）。
3. **橙色只记两个值**：`#bc4710` = 一切橙色文字和橙色按钮底；`#ee7035` = 只做装饰（侧栏选中竖条、页签下划线、logo）。按钮/链接悬停一律用更深的 `#9a3a10`（系统原来是变浅，变浅会掉对比度）。
4. **表单控件不继承字体**：每个 `<button>`、`<input>`、`<select>`、`<textarea>` 的 inline style 都要写 `font-family: inherit;`。

## B. 字体

- 系统字体族：**Plus Jakarta Sans**（本地 woff2，200–800 七个字重，`src/app/styles/fonts.scss`；全局 `:root { font-family: 'Plus Jakarta Sans', sans-serif }`，`src/app/styles/global.scss`）。另有 Gwendolyn（仅报价单签名用，原型不用）。
- Plus Jakarta Sans 不含中文字形，中文回退 **Noto Sans SC**，再回退系统中文字体。
- Google Fonts css2 链接（直接粘到 helmet 的 `<link href="…">`）：

```
https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700;800&family=Noto+Sans+SC:wght@400;500;600;700;800&display=swap
```

- 完整 font-family 写法：

```
font-family: 'Plus Jakarta Sans', 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif;
```

- 字重：标题 800、按钮 700、正文/输入 500、普通文字 400。中文 800 在 Noto Sans SC 中为 ExtraBold，标题可直接用；表格单元格中文改 600。
